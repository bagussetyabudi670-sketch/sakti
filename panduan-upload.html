Untuk: ... — ...

⚠ PENTING: Harus Login Google Dulu

Sebelum membuka folder, pastikan Anda sudah login Google dengan akun yang benar. Kalau belum login, folder tidak bisa dibuka.

Langkah-Langkah
1

Cek Login Google

Buka gmail.com di browser Anda. Pastikan sudah login dengan akun yang benar.

2

Hanya 1 Akun Google

Kalau Anda login dengan lebih dari 1 akun Google (misal akun pribadi + akun kantor), logout dulu semuanya. Sisakan 1 akun saja. Kalau tidak, folder bisa gagal terbuka.

3

Klik Tombol di Bawah

Setelah login 1 akun, klik tombol hijau "Buka Folder Bukti Dukung" di bawah. Folder akan terbuka di tab baru.

4

Upload File

Di dalam folder, klik "+ New" atau drag-and-drop file dari komputer ke folder. File akan otomatis tersimpan.

5

Selesai

Tutup tab folder Drive. Bukti dukung sudah terunggah ke folder yang benar.

Format file yang diperbolehkan: PDF, Gambar (JPG/PNG), Excel. Maksimal 5 MB per file.

Buka Folder Bukti Dukung

Tombol akan membuka folder Google Drive di tab baru. Pastikan sudah login Google dulu.

Pertanyaan Umum

Folder tidak bisa dibuka / muncul "You need access"?
Pastikan Anda sudah login Google. Kalau masih error, coba logout semua akun Google, login 1 akun saja, lalu klik tombol lagi.
Muncul tulisan "Login untuk menambahkan file"?
Klik "Login", login dengan akun Google Anda, lalu coba upload file lagi.
File tidak muncul setelah diupload?
Tunggu 5-10 detik. File akan muncul di folder. Kalau tidak, coba refresh halaman (F5).
Ukuran file terlalu besar?
Maksimal 5 MB per file. Kalau lebih, kompres file terlebih dahulu, atau bagi jadi beberapa file.
